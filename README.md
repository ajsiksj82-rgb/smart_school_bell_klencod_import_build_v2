# الجرس المدرسي الذكي — نسخة تطوير أولية

هذا مشروع Flutter عربي بقاعدة بيانات SQLite محلية، مع شاشات إدارة المدارس والمباني والجداول والإجازات والسجل وشريط تقدم الحصة.

## إصلاح بناء APK

كان سبب فشل البناء في GitHub Actions هو غياب ملفات منصة Android، وبالأخص `android/app/build.gradle` أو `android/app/build.gradle.kts`. ملف `pubspec.yaml` موجود في جذر المشروع، لكن مجلد Android لم يكن ضمن الأرشيف.

سير العمل الموجود في `.github/workflows/build.yml` يفعل الآتي:
1. يتحقق من أن `pubspec.yaml` موجود في جذر المستودع.
2. ينشئ ملفات منصة Android بواسطة `flutter create` إذا كانت ملفات Gradle الأساسية غير موجودة.
3. يشغّل `flutter pub get` و`dart format` و`flutter analyze` و`flutter test`.
4. يبني APK إصدار Release.
5. يرفع ملف APK كـ Artifact باسم `smart-school-bell-release-apk` عند نجاح جميع الخطوات.

لضمان أن البناء يستخدم الجذر الصحيح، ارفع **محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub** بحيث يكون `pubspec.yaml` في المستوى نفسه مع مجلد `lib` وملف `.github`.

## التشغيل المحلي

1. ثبّت Flutter SDK وAndroid SDK.
2. من جذر المشروع نفّذ:
   `flutter create --platforms=android --project-name smart_school_bell --org com.smartskills .`
   (يمكن تخطي هذا الأمر إذا كان مجلد Android مكتملًا).
3. نفّذ:
   `flutter pub get`
   `dart format lib test`
   `flutter analyze`
   `flutter test`
   `flutter build apk --release`

## الوظائف الموجودة في هذه النسخة

- قاعدة بيانات SQLite محلية تُنشأ تلقائيًا عند أول تشغيل.
- إدارة إضافة المدارس والمباني.
- إنشاء أحداث جدول يومي حسب المبنى واليوم، مع نوع الحدث والوقت والوصف والمادة.
- إدارة الإجازات على مستوى المدرسة.
- شاشة سجل محلي لتشغيل الجرس اليدوي.
- بطاقة تقدم الحصة الأصلية مرتبطة بمزوّد SQLite، وتحسب النسبة من الوقت الحالي.
- واجهة عربية RTL.

## قيود مهمة قبل الاستخدام المدرسي

- زر الجرس اليدوي يستخدم تنبيه Android الافتراضي (`SystemSound.alert`) وليس ملف صوت جرس مخصصًا.
- الجدولة التلقائية الحالية تعمل فقط أثناء بقاء التطبيق مفتوحًا؛ لا توجد بعد خدمة Android أصلية موثوقة لتشغيل الجرس عند إغلاق التطبيق أو إعادة تشغيل الهاتف.
- يلزم استكمال واختبار صلاحيات التنبيهات الدقيقة وإعادة الجدولة بعد إعادة تشغيل الهاتف، وتجربة إعدادات البطارية ومخرج AUX على الهاتف الفعلي.
- النسخ الاحتياطي/الاستعادة واختيار ملفات صوت متعددة وتعديل/حذف المدارس والمباني والأحداث ليست مكتملة بعد.

## مخطط قاعدة البيانات

- `schools`: المدارس.
- `buildings`: المباني المرتبطة بالمدارس.
- `schedules`: جدول لكل مبنى ولكل يوم أسبوع.
- `bell_events`: أحداث الجرس المرتبطة بجدول اليوم.
- `holidays`: إجازات المدرسة.
- `execution_logs`: سجل تشغيل الجرس والأخطاء.
- `app_settings`: إعدادات مستقبلية.
